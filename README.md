This project is a fun little simulator that simulates atoms and particles. I don't really know what else to say except it was made with Claude (Mainly Opus 5.5 but I switched to Fable for an engine rewrite
so it would distribute performance better).

What it has:
2D and 3D modes, every element, molecule creator, decently accurate sim but if you want it to be more accurate there are settings that require a very powerful CPU. There are many other things, see for yourself.

Limitations:
Requires a beefy CPU (tested on an AMD Ryzen 9 7950X3D). 16 threads runs best, for me.
Not 100% accurate, as that would require a supercomputer
Only so many atoms can be simulated, limit is 20,000
Other inaccuracies are discribed in the Physics section on the top right of the menu.

There is much more
